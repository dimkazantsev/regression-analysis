# Regression Analysis Lab

Интерактивный учебный материал по регрессионному анализу.

## Что уже внутри

- живая песочница связи X и Y;
- распознавание направления связи;
- ручная подгонка линии OLS;
- интерпретация коэффициентов;
- эксперимент с влиятельным выбросом;
- поиск максимального остатка;
- диагностика гетероскедастичности и нелинейности;
- сравнение моделей по test RMSE;
- финальный квиз из 10 вопросов;
- сохранение прогресса в браузере.

Сайт не требует сборки: `index.html`, `styles.css`, `app.js`.
